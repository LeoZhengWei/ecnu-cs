# CV 考前速记｜按 16 章整理

按章排，每章 4-7 条，一条一个方法。**别一口气全看**，一章一章背，一章也就六条。
每条还是老格式：输入是什么 → 中间每步在干嘛 → 输出是什么，最后半句点一下想法。不写公式。

## 第1章 概论

1. ★ **计算机视觉在干什么**：输入图像或视频，先把现实里的形状、位置、运动恢复出来，再判断「这是什么、在哪、在干嘛」，输出识别和理解的结果。说白了就是让机器照着人眼「采集 → 传导 → 大脑解析」走一遍，中间换成算法。
2. **Marr 三层框架**：把视觉拆成「算什么（计算理论）→ 怎么算、中间怎么表示（表征与算法）→ 拿什么实现（硬件）」三层，输出一套分析问题的框架。爱考三层各回答什么问题。
3. ★ **为什么难**：同一个物体换个视点、换个光照、被挡一下、背景一乱，成像就完全变样；目标大小、场景复杂度也会变。所以算法得抓那些不容易变的东西。后面整门课的特征方法，都是在还这笔债。
4. **传统 vs 深度 vs 机器学习**：传统是「预处理 → 人工定好的特征 → 分类器」分段做；深度把这几步塞进一个网络自己学；机器学习是喂样本让模型学出一个从输入到输出的决策函数，再拿它预测新样本。输入输出没变，变的是「特征谁定」。后来图加文字一起进模型、输出文字答案，输入从单模态扩到多模态。

## 第2章 图像处理基础

1. ★ **卷积与相关**：输入一张图加一个小核，核翻转（卷积）或不翻（相关）后逐像素滑，盖住的地方对应相乘求和，填成新图一个像素。换个核就换效果：全 1 平滑、差分核提边缘、锐化核补细节。输出一张结果图，CNN 的名字就来自这套滑窗加权求和。
2. ★ **平滑滤波**：3×3 窗口滑过带噪图，均值取平均、高斯按离中心远近加权、中值排序取中间那个专治孤立黑白点。输出平滑图。想法是噪声随机又孤立，邻域一平均就抵消；代价是边缘跟着糊一点。
3. **锐化**：输入模糊图，用一阶微分（Sobel / Roberts）或二阶（拉普拉斯）把灰度突变的地方找出来加回原图，或在频域抬高高通，输出边缘更清楚的图。细节本来就是高频。
4. **空域 vs 频域增强**：空域直接对像素做逐点或邻域运算；频域先傅里叶变换到频率上，挑着改高频（细节噪声）或低频（明暗底色），再逆变换回来。输出都是增强图，换个域只是更好下手。
5. ★ **高斯与拉普拉斯金字塔**：原图当第 0 层，每层先平滑再隔点降采样、宽高减半，越往上越小越糊只剩轮廓；上采样反过来放大加倍，空出来的位置得插值补值。拉普拉斯每层存的是「原图减掉放大还原图」剩下的细节，正好对应频谱里一个环带，拿去压缩、融合、去噪。输出一组多分辨率图，找小东西看底层、认整体看顶层。
6. **灰度化与几何变换**：RGB 按分量或加权压成单通道，再做平移、旋转、缩放、翻转把像素搬到新坐标，输出新图。看着基础，数据增强和后面所有坐标变换都靠它。

## 第3章 图像的特征

1. ★ **颜色特征**：输入 RGB 图，把颜色分桶统计每桶出现多少次得直方图，也能算颜色矩、颜色集。输出一条只讲「有哪些颜色、各占多少」的全局向量，位置和形状全丢掉，所以对平移旋转不敏感、算得快，常用于以图搜图和肤色检测；但两图颜色像就分不开。
2. ★ **边缘检测**：输入灰度图，用水平竖直小算子（Sobel / Roberts / Prewitt）算一阶差分、或用拉普拉斯算二阶，灰度平稳处接近 0、边界处突然变大，超阈值判边缘点；Canny 多做一步非最大抑制把粗边压细再连起来。输出边缘图。想法是边缘就是灰度不连续。
3. ★ **Harris 角点**：输入灰度图，每个像素用小窗口里的 x、y 差分算一个 2×2 自相关矩阵，再算角点响应；窗口往各方向挪一点点，平坦区不变、边缘只一个方向变、只有角点各个方向都猛变。响应超阈值又是邻域极大就留下，输出角点坐标，专门给匹配、拼接当锚点。
4. ★ **SIFT**：输入一张图，先在高斯差分（DoG）金字塔上找尺度变了还在的极值点当关键点，再用邻域梯度直方图定个主方向，把坐标轴转过去，取 16×16 邻域切成 16 个 4×4 块、每块数 8 个梯度方向，拼成 128 维向量。输出每个点一个描述子，旋转、缩放、亮度变了都稳。SURF 是它的加速版，改用 Haar 小波响应。
5. **纹理与形状特征**：纹理靠灰度共生矩阵统计出熵、能量、对比度；形状看轮廓算密集度、体态比。输出一组不依赖颜色的描述量，补上颜色特征顾不上的那一面。
6. **特征怎么挑**：全局的颜色、纹理适合检索分类，局部的角点、SIFT / SURF / HOG / LBP 适合匹配拼接；手工特征是人事先定死的，深度特征是网络从数据里自己学出来的。这条就是整门课前后半的分界。

## 第4章 图像对齐

1. ★ **特征匹配 SSD / NCC**：输入两幅图提好的特征或灰度块，SSD 把对应像素差平方累加、NCC 先各自减均值再做相关，越小或越大说明越像；SIFT 这类归一化描述子直接算欧氏距离。输出候选匹配点对。NCC 比 SSD 强在整体变亮变暗、对比度变了也不怕。
2. ★ **比值测试**：把「最近邻距离 ÷ 次近邻距离」算出来，比值大说明好几个候选都挺像、这匹配含糊，直接扔掉。输入一堆候选，输出更干净的点对。想法是提前把模棱两可的剔掉，别留给后面。
3. **仿射与单应变换**：仿射有 6 个参数、一对点给 2 个约束，凑 3 对就能解；单应 H 还管透视投影，要 4 对。解出矩阵后把 b 图每个像素坐标乘过去，落到非整数位置就插值，输出变形后的图。用少数几个点定住整幅图的变形规则。
4. **最小二乘估计**：输入超过最少数量的匹配点对，把「投过去应该落在哪」的误差平方和凑成一个目标，一次求出最贴合所有点的变换参数，输出变换矩阵。点对越多越稳，但一个错配就能把结果带歪，所以得先 RANSAC。
5. ★ **RANSAC**：输入一堆可能混着错配的点对，反复随机抽 4 对算一个 H，把全部点代进去算重投影误差，误差小的算内点、大的算外点；挑内点最多的那组 H，最后只对内点重做一次最小二乘精修。输出干净点对和准确的 H。不跟错配硬刚，靠随机试模型加多数点投票。
6. ★ **配准与全景拼接**：输入两张有重叠、不同视点拍的图，各自提特征 → 匹配 → 估出变换矩阵 → 把待对齐图搬到参考图坐标系 → 缝合接缝，输出对齐图和全景图。相机绕光心纯转着拍才拼得顺。刚体对齐是整图只用一套旋转平移（建筑、航拍、全景）；非刚体改用薄板样条、网格形变让局部各自拉伸（人脸、器官）。

## 第5章 二值图像分析

1. ★ **Otsu 最大类间方差**：输入灰度直方图，挨个灰度把像素劈成前后景两堆、算类间方差，挑方差最大那个当门槛，逐像素比大小记 0 或 1，输出二值图。就是自动找「分得最开」的那一刀。
2. **迭代阈值与局部阈值**：先拿灰度均值当 T 分两组，各算均值再取中间当新 T，反复到 T 几乎不动，输出二值图；光照不均一个全局 T 不够，就切成小块、每块按自己邻域定门槛。门槛随位置变而已。
3. ★ **腐蚀膨胀与开闭**：输入二值图和一个 3×3 结构元，腐蚀要整块都落在白区才留、物体瘦一圈把粘连分开；膨胀只要碰到白就把中心并进来、补上小洞断口。先腐后膨叫开，去噪点又不怎么改大物体面积；先膨后腐叫闭，填洞接细缝。输出修过形状的二值图。
4. ★ **连通成分标记**：输入二值图，定好 4 邻域还是 8 邻域算「挨着」，从头扫，碰到一个没编号的白点就发新标签，顺着邻域把连得上的全染同一个号。输出标记图，顺带知道有几个物体、各在哪多大；沿边界顺时针走一圈还能得轮廓和链码。
5. **骨架化与距离变换**：输入一个白色区域，中轴法用欧氏 / 街区 / 棋盘距离找每个点到边界的距离，或拿 3×3 窗口一层层剥掉边界，输出单像素宽的骨架。把一片区域压成一根线，认笔画、量形状都方便。
6. **区域表达与形状特征**：输入二值图，RLE 把连续的白像素记成「起点＋长度」好算面积，再算质心、方向、伸长率；欧拉数是连通块数减洞数。输出一组形状描述量，扫码、工业零件定位这类活靠它。

## 第6章 纹理特征及分析

1. ★ **灰度共生矩阵 GLCM**：纹理由重复的小基元构成。输入灰度图，定好一个方向和距离（比如右 1 下 1），滑窗数「灰度 i 和 j 隔着这段距离成对出现」多少次，填成方阵。输出一张把灰度空间分布记下来的矩阵，粗细、方向、周期性全藏在这种搭配里。
2. **GLCM 的五个统计量**：输入共生矩阵，把元素累加成对比度、能量、熵、均匀度、相关性几个数，输出一条纹理特征向量。等于把「看起来粗不粗、乱不乱、有没有规律」变成能比大小的数字。
3. ★ **LBP**：输入灰度图，每个像素跟周围一圈邻居比谁亮，绕一圈串成 0/1 编码；再切成 16×16 小块，各统计编码出现次数、归一成直方图，全部拼起来。输出一条整图特征向量，只比相对明暗所以光照变了也不怕，虹膜识别、纹理分类常用。
4. **自相关函数**：输入纹理图，把图平移一小段后跟原图算相关性，看曲线掉得快不快、有没有周期，输出基元大小和粗细。粗纹理衰减慢、细的快。
5. **频谱法（傅里叶 / Gabor / 小波）**：输入纹理图，做傅里叶看能量谱落在哪些方向和环带上、用 Gabor 挑方向做滤波、用小波按多尺度分解，输出主方向、周期、疏密这些特征。空域里看不清的重复规律到频域就分得开；缺点是全局变换丢局部位置，水、烟这种没周期的自然纹理就一般。
6. **纹理分类与合成**：输入一张大图，滑窗逐块算 GLCM 特征送 K-means，输出每块一个纹理类别、映射回原图成区域划分图；合成反过来，用 MRF 随机改灰度、按概率取舍到稳定，造出看着像的新纹理。

## 第7章 图像分割

1. **阈值分割**：本质是逐像素分类，输入灰度图，用 Otsu 或迭代均值找分界、光照不均就分块取局部阈值，输出二值图。跟第 5 章一套东西，只是这里目的是把前后景分开。
2. ★ **区域生长与分裂合并**：生长是先挑个种子点，把 4/8 邻域里灰度颜色跟种子（或当前区域均值）相近的收进来，再对新点重复到长不动，输出一块区域；分裂合并反过来，把整图当一块，内部灰度不齐（看均方差）就劈成四块、相邻又齐就合回去。一个从点往外长、一个从整图往下切，找的都是「里面齐、彼此不同」。
3. ★ **聚类分割（K-means / Mean Shift）**：输入像素的颜色、强度（最好把坐标也当特征），K-means 定好 K 类、反复把点往最近的中心归并更新中心；Mean Shift 不预设 K，让滑动窗口每步朝窗口内点的均值也就是更密的地方爬到收敛。输出每像素一个簇号的分割图。
4. ★ **图割 Graph Cut**：输入图像，把每个像素连成带权图，边权看两点像不像、各自多像前景背景，再求最小割（最大流）把联系最弱处一刀切开。输出前景/背景二分割。把分割变成「切一刀」，不用种子也不用手画轮廓。
5. **活动轮廓 Snake**：输入图和一条手画在目标附近的初始曲线，内力拉着曲线别太皱别断，图像梯度把它往真边缘吸，两边能量加起来最小时曲线贴紧物体，输出一条闭合边界。它不逐像素判类，是让一条会变形的线自己爬过去。
6. ★ **水平集与深度版**：把二维曲线抬成三维曲面的零水平集（符号距离函数为 0 那一圈）让它自己演化，好处是轮廓能自动分裂合并；深度版干脆让 CNN 直接预测这个水平集函数，能量项改成可微损失，端到端训练。输出轮廓或分割图，适合医学那种形状会分叉的复杂结构。

## 第8章 语义分割

1. ★ **语义分割 vs 实例分割**：输入一张图，语义分割给每个像素标个类别、不管同类有几个；实例分割连「第几个个体」也分出来。输出都是和原图同尺寸的类别图，一个管「是什么」、一个管「是哪个」。
2. ★ **FCN 全卷积化**：输入任意尺寸三通道原图，把分类网尾部的全连接层全换成卷积层（这样多大图都能进），一路卷积加池化下采样压到 1/32 成粗糙热图，这步把「是什么」抽出来、位置糊了；再上采样放大回原尺寸把类别对回每个像素。输出和原图同大的每像素类别分数图，取最大当类别。下采样管认得对，上采样管对得准，端到端还能复用预训练分类网。
3. ★ **FCN 跨层融合与优缺点**：输入各层特征图，把 pool3、pool4 这些浅层细节跨层加回深层预测，输出更细的分割；损失是最后一层在空间上逐像素的损失之和，也能用各层梯度损失之和一起算。优点是任意尺寸、能复用分类网微调；缺点是 8 倍上采样还是偏糊，而且没顾上像素之间的关系。
4. ★ **编码器-解码器（U-Net / SegNet）**：左边编码器逐级卷积加池化，图越来越小越来越抽象、抓「这块大概是什么」；右边解码器对称地卷积加上采样，把尺寸还原、把语义落回具体位置。U 形跳跃连接把同层还没压糊的浅层特征直接拼过去，边缘才画得准。输出逐像素类别图。
5. ★ **空洞卷积 / DeepLab / ASPP / CRF**：输入特征图，空洞卷积在卷积核里插空、隔几点采一个，参数没多、图没缩却能看到更大一片；ASPP 把几个不同空洞率并排跑，一次收进大目标、小目标和多尺度上下文；最后接全连接 CRF，按相邻像素像不像把边界修顺。输出比 FCN 精细得多的分割图。别靠一味下采样换语义。
6. **注意力机制**：输入特征图，通道注意力（SE-Net）学每个通道该给多大权重、空间注意力（CBAM）吐一张位置掩膜、自注意力（Non-Local）建全局范围内两两的关系，输出加权后的特征。想法是让网络自己挑重点，别对所有位置一视同仁。

## 第9章 摄像机模型与多视几何

1. ★ **针孔成像与四个坐标系**：输入现实里一个 3D 点，先用旋转平移（外参）从世界系搬到摄像机系，再按小孔用焦距、主点投到图像物理系，最后按缩放平移换成像素坐标 (u,v)。三步连起来就是投影矩阵，内参管相机自身（焦距、主点、倾斜、缩放），外参管相机摆在哪朝哪（R、t），深度在这一步被丢掉。
2. **镜头径向畸变**：真镜头不像理想针孔，会把直线拉成桶形或枕形。标定时先把这层非线性畸变扣掉，后面算位置才准。
3. ★ **摄像机标定（张正友 / DLT / RAC）**：输入从不同角度拍的几张平面棋盘格，找出已知 3D 点和像点的配对，DLT 直接解线性方程、RAC 借径向一致约束先求外参、张正友先解内外参再整体优化。输出内参、外参或整个投影矩阵。张正友不用高精度标定块又比自标定准，所以最常用。
4. **摄像机自标定**：输入多幅图里配好的对应点，假定内参不变，靠基线、极点、极线这套对极几何约束反求内参 K，输出内参。不用标定块最灵活，代价是精度差、不稳。
5. ★ **对极几何（F / E / 八点法）**：输入两个视点和两幅图，把两个光心连成基线，过基线的平面和像平面交出极线；左图给一个点，右图对应点必落在那条极线上，这个约束写在基本矩阵 F 里，配内参换成本质矩阵 E、再 SVD 拆出 R 和 t。输出 F、E 和相机运动。找匹配从满图二维瞎搜压成一条线上找。
6. ★ **SFM 与三角测量**：输入几张图里配好的对应点，由 F 和 K 换出 E、拆出每帧的旋转平移，再用两个视点的成像光线相交反算 3D 点。输出相机运动加一堆稀疏三维点。光看「点在几张图里怎么跑」，就把相机怎么动和场景结构一起反推出来。

## 第10章 三维重建

1. ★ **重建的整体流程**：先标定相机 → 立体匹配找对应点 → 算深度 → 把场景表示出来（深度图、点云、网面）。单视点靠先验、多视图靠几何，走的都是这条线。
2. ★ **视差与深度**：左右相机光轴平行、已经标定时，同名点在两图里的横坐标差就是视差；视差跟深度成反比，差得越大东西越近。用焦距和两台相机的间距（基线）把视差换成距离，输出深度图。单张图丢掉的深度就靠这个补回来。
3. **立体匹配与极线校正**：输入左右图，先把极线校到同一行，再在这一行的小邻域里按外观一致性找对应点，最后拿标定好的内外参把 2D 点对换算成 3D 点。输出对应点和三维坐标。匹配准，深度才准。
4. **三角测量（含主动式）**：已知基线和焦距，同名点对靠三角形相似反算深度；还有主动版，往物体投红外、看 CCD 上光斑偏移多少算距离。输出每点深度。都是拿一个三角形做文章。
5. **深度图插值补洞**：输入有空洞的深度图，挑附近三个不共线的已知点凑个平面，或用二元线性、鲁棒回归、B 样条估出这点的深度，把空白补成连续表面，输出补完整的深度图。
6. ★ **点云到网面**：输入稀疏点云，先采样、过滤、填洞，定好点与点之间的连接关系，生成三角形网面，最后贴纹理显示。输出一个能看、能量测的三维模型。离散的点得连成面才算重建完。

## 第11章 光流计算

1. ★ **光流与三个假设**：输入相邻两帧，假定同一个点亮度不变、帧间位移很小、一小块邻域里大家运动相似，求它每帧的瞬时速度 (u,v)，输出一张光流场。说白了就是想找出帧与帧之间谁对应谁、往哪动。
2. ★ **约束方程与孔径问题**：把「亮度恒定」用泰勒展开摊开，拿横纵梯度和帧间灰度差凑出一条约束式；可一个点有两个未知速度、只有一条式子，梯度不够时连方向都测不出，这就是孔径问题。所以必须再补一条约束才解得动。
3. ★ **Lucas-Kanade**：输入两帧和要跟的点，假定一个小窗口里像素运动都一样，把邻域攒的一堆方程用加权最小二乘解出这点速度，输出稀疏特征点的位移。拿邻域凑方程把欠定问题补成可解，配角点又准又快。
4. ★ **Horn-Schunck**：输入两帧，把「亮度不变」的误差和「相邻点速度别差太多」的全局平滑项加权拼成一个能量，用变分法反复迭代压到最小，一口气给全图每个像素都算出速度，输出稠密光流场。靠全局平滑把条件补全。
5. ★ **金字塔由粗到细**：运动一快「小位移」假设就垮，先把图缩成多层金字塔，从最糊的顶层算个粗光流，再把上层结果当下层初值一层层往下细化迭代，直到回原图，输出修正后的光流。专治大位移。
6. **稠密 vs 稀疏与应用**：逐点全算叫稠密（HS、Farneback），只挑特征点算叫稀疏（PyrLK）；稠密还能补遮挡留下的空洞。光流场拿去做跟踪、插帧、SLAM，是后面几章的基础输入。

## 第12章 目标识别技术基础

1. **任务定义与难点**：输入一张图，先判有没有目标（检测）、有再定位置和尺度、甚至分出哪些像素属于它（分割），输出框或掩膜。难在外观会变形、光照会变、运动模糊、背景还可能撞脸。
2. ★ **滑动窗口**：拿不同大小的框在图上逐格滑，每格交给训好的分类器打「有/无目标」的分，攒一堆高分框再用 NMS 去重叠，输出目标框和类别。想法直白，就是全图穷举太慢。
3. ★ **特征＋分类器**：先攒正负样本，提 SIFT、HOG、LBP 这些人工特征，再训 SVM、AdaBoost 或神经网络；滑窗时每格就靠它判。输入一批样本，输出一个二分类器。传统识别链的功夫全在「特征怎么挑、分类器怎么训」。
4. ★ **Viola-Jones 级联**：输入人脸/非人脸样本，用几种矩形 Haar 特征扫窗口，AdaBoost 一轮轮挑最能分的弱分类器、把分错的样本权重抬高再训下一个，拼成强分类器再串成几十层级联；前几层飞快扔掉明显是背景的窗口，通过的才往后走，最后 NMS 出人脸框。输出框，用「先便宜地拒绝」换来了实时。
5. ★ **视觉词袋 BoVW**：训练图全提 SIFT 局部特征，丢进 K-Means 聚类，聚类中心就是一本 K 个「视觉单词」的词典；每张图把特征点翻成最近的词、数词频，输出 K 维直方图当这张图的向量，送分类器给类别。把图当一袋没顺序的词，位置丢了照样认类别。
6. **从显式滑窗到卷积隐式滑窗**：不用一个个裁框，整图一次喂进网络，卷积核天然在图上滑、权重还共享，YOLO、SSD、Faster R-CNN 都这么干。输入整图，一次前向出所有框，比显式滑窗快得多，顺手接上第 14 章。

## 第13章 运动跟踪

1. ★ **跟踪是什么、跟检测差在哪**：输入首帧一个框，后面每帧预测它的新位置并把同一目标连成一条轨迹，输出位置、速度这些状态。检测只管当前帧有没有，跟踪要用上时序；每帧只做静态检测的叫「伪跟踪」。分单目标/多目标，在线只能用过去帧、离线还能借未来帧所以更准。
2. ★ **卡尔曼滤波**：输入上一帧的最优状态和这一帧的检测框，预测步用运动模型把位置往前推一帧（不靠观测，不确定度变大），更新步拿观测减预测的残差、按过程噪声和观测噪声谁更可信加权折中。输出这一帧更准的状态和收紧的不确定度，下一帧接着用。检测漏一帧，预测也能顶上。
3. ★ **Mean Shift / CamShift**：首帧把目标框做成颜色直方图当模板，当前帧候选框也算一份；模板里占比高、候选里偏偏少的颜色给大权重，按权重算重心把搜索窗往那挪，反复爬到相似度峰值，停下就是新位置。CamShift 顺手把窗口大小和转角也调了。输出每帧一个框，快，但背景颜色一像就容易跟丢。
4. ★ **相关滤波（CSK / KCF）**：首帧框出目标，对着一张「中间亮、边缘渐暗」的理想标签训出滤波器；之后每帧在上一帧位置附近抠一块，加余弦窗压边界、FFT 转到频域跟模板逐点相乘再逆变换回来，得到响应热力图，最亮点就是新位置，顺手在线更新模板。输出每帧新框，频域相乘所以快，还能边跟边适应外观变化。
5. **粒子滤波**：课件把它和卡尔曼、相关滤波并列。输入一堆带权重的「粒子」表示目标可能在哪，每帧按运动模型把粒子撒开、再按当前观测像不像重新定权重、重采样，输出新的位置估计。不像卡尔曼只认一条高斯分布，多峰、非线性的情况更扛得住。
6. ★ **多目标跟踪（ByteTrack 这类）**：检测器给出高分框和低分框，卡尔曼先预测每条轨迹下一帧的位置，高分框先做主关联，低分框再捞回被短暂遮挡的目标、过滤背景虚警，输出各条轨迹。不依赖 ReID 外观特征也跑得快。

## 第14章 智能目标识别与跟踪

1. ★ **R-CNN**：输入一张图，先用选择性搜索抠约 2000 个可能含物体的候选框，逐个拉成固定尺寸过 CNN 提特征，再喂 SVM 判类别，输出类别和框。慢在两千个框各卷一次，重复算得太多。
2. ★ **SPP Net / Fast R-CNN**：整图只卷积一次，空间金字塔池化或 RoI Pooling 把任意大小的框特征压成固定长度，softmax 替掉 SVM，还把边框回归并进网络用多任务损失一起训。输出类别概率加修好的框。共享卷积是提速的关键。
3. ★ **Faster R-CNN / RPN**：输入整图出一张特征图，让 RPN 在上面滑窗，对每个锚框先判「有没有东西」再微调成候选框，后面接着分类和精修，输出框和类别。用网络自己产候选框，替掉了最费时的选择性搜索。
4. ★ **YOLOv1**：输入整图切成 7×7 网格，物体中心落哪格哪格负责，每格吐 2 个框（中心、宽高、置信度）加一组 20 类概率，凑成 7×7×30 的张量；再按阈值扔低分框、NMS 并掉重叠的，输出所有框和类别。不要候选区、把检测当纯回归，一次前向就完事，代价是网格太粗、密集小目标和定位吃亏。
5. ★ **SSD**：输入图（训练时带真值框），在 8×8 浅层和 4×4 深层好几张特征图上一起检，每格先摆一组不同形状的默认锚框，网络只学往哪微调一点和框里是各类别的置信分；训练时先把默认框和真框配成正负样本。输出一堆带类别和位置的框。浅层分辨率高管小物体、深层感受野大管大物体，把 YOLO 的速度和锚框的精度凑一块。
6. **两阶段 vs 一阶段与评价**：R-CNN 系先提框再分类（two-stage，精度优先），YOLO / SSD 系整图直接回归（one-stage，速度优先）；两边都得同时做分类和框回归 (x,y,w,h)，输出带分框再 NMS 去重叠，最后比平均精度 mAP。分类管「是什么」，回归管「在哪」。

## 第15章 智能三维重建

1. ★ **传统重建流水线（SfM / COLMAP → MVS）**：输入多视角照片，先提特征匹配，增量式 SfM 估每帧位姿、三角测量出稀疏点、再用光束法平差把所有参数一起优化，输出相机位姿和稀疏点云；MVS 在相机已知的前提下补稠密深度。传统这路靠优化解几何，智能这路让网络直接回归。
2. **单图深度估计（粗细两网）**：输入一张 RGB，粗网络先给出全局的大致深度，细网络再按边缘和局部细节修一遍，两个网分开训练、各自回传，损失用尺度不变误差，输出一张深度图。没多视图几何可用时，就靠数据里的先验猜深度。
3. ★ **MVSNet**：输入一张参考图、几张源图和相机参数，CNN 给每张图提特征，按可微单应把源图特征一个个 warp 到不同候选深度平面上（相当于假设某个深度、看各视角对不对得上），堆成三维代价体，3D CNN 正则化后回归出深度图，最后多视角融合成稠密点云。输出深度图和点云。把「假设深度 → 比一致性」做成可学的。
4. ★ **NeRF**：输入多视角照片和每张的相机位姿，用一个 MLP 把场景记成「3D 坐标＋观察方向 → 颜色＋体密度」的连续函数；渲染时沿每条光线采一串点，按密度把颜色累加成一个像素，跟真图比、误差顺着可微体渲染回传改网络。训完换个新机位就吐出那个角度的图。不存体素不建网格，缺点是慢、只能静态场景。
5. ★ **3D Gaussian Splatting**：拿 SfM 的稀疏点云初始化一堆各向异性 3D 高斯，每个带中心、协方差（形状朝向）、不透明度，再加球谐系数管不同视角的颜色；渲染时把高斯按相机投影、泼溅到 2D 可微地画成图，按和实拍图的误差调参数，过程中自适应拆分增删。输出实时（30 帧以上）的新视角图。用可微的离散高斯基元替掉沿整条光线采样，所以快得多。
6. **点云生成网络**：输入一幅图加一个随机向量，编码器压成嵌入，预测器吐一个 N×3 矩阵（每行一个 3D 点），输出无序点云；用 CD / EMD 量两个点集差多远，随机向量不同还能一次采样出多个合理形状。重建不一定非得从多视图来，也能直接让网络「想」出一个三维形状。

## 第16章 视觉语言模型

1. ★ **Transformer**：输入一句话先变成词向量（word2vec、GloVe、one-hot 都行），叠一层正余弦位置编码把「谁在前谁在后」补回去，再堆 6 个编码器块，每块里多头注意力算词与词的权重、对所有词的值加权求和，后面过个前馈网络。输出每个词一份带上下文的高维表示，接个任务头就能分类、翻译、生成。一口气看完整句还能并行，替掉了 RNN 一个词一个词顺推。
2. ★ **BERT / GPT 与预训练+微调**：先拿大规模语料预训练出通用底座（BERT 遮住几个词让模型猜、学双向上下文；GPT 走生成式预训练），再针对具体任务换输出头、用少量标注微调。输出随任务变，是类别、答案或每个词的标签。省得每个任务从头训一个模型。
3. ★ **CLIP**：输入配好对的图和文字，图过图像编码器、文过文本编码器，各自压成同一个嵌入空间里的向量；训练用对比学习，配对的往一起拉、不配对的往开推。输出能直接算的图文匹配分数，给一组候选词就能判这张图更像哪个、也能做图文检索。拿自然语言当监督、类别不提前定死，所以没见过的新类也能零样本认。
4. **BLIP 与图文任务**：用跨模态编码器-解码器把「理解」和「生成」统一到一份模型里，输入图（可加问题），输出文字，能跑图文检索、图像字幕、视觉问答、视觉对话；ALBEF 是先对齐再融合、还加动量蒸馏。一份模型干好几样活。
5. ★ **BLIP-2 / InstructBLIP**：冻住预训练好的图像编码器和大语言模型，中间只训一层做图文对齐、分两阶段学，省掉从头端到端的大开销；InstructBLIP 再用指令数据微调，多个数据集上零样本表现更强。输出文字答案。思路是「两端不动、只训桥」。
6. **LLaVA 与视觉指令微调**：借 GPT-4 生成图文指令数据、用 CLIP 提视觉特征，把图像和语言指令一起喂进大模型微调；输入图加一句问题，输出文字回答。让模型学会照着人的吩咐看图说话。
7. **多模态大模型怎么练出来**：从 GPT-4 到 GPT-4o，输入从文本扩到图文、再融进音频，靠文本指令驱动出视觉理解结果；训练按「预训练 → 有监督微调 → 奖励建模 → 强化学习」四步走。这章的落点是：视觉和语言被放进同一个模型，任务用一句话描述就行。

---

一口气串起来：前半门课是「人先定好该看什么特征，再用分类器或几何约束算出结果」；后半门课是「把这几步塞进网络，先压小认语义、再放大对位置，或者干脆让网络把场景和图文关系自己记下来」。
