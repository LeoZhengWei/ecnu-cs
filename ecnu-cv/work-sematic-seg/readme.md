# 语义分割
## 评价指标
### 混淆矩阵
矩阵的行是真实类别，列是预测类别。
行号：真实号
列号：预测号
某行列Mij表示“真实是i，预测是j”的像素个数，标注为Void的像素不放进这张表。
对角矩阵为预测对的像素数，其他位置为预测错的像素数；
对i类，从矩阵中取出三个数：
· TPi：真实是i，预测也是i，对角线Mii
· GTi：真实是i的全部像素，第i行加起来
· Predi：预测成i的全部像素，第i列加起来
### 评价参数
#### 1. 精确率Precision
``` 
Precision(i) = TPi / Predi
```
模型标成的这类像素中，有多少真是这类。
#### 2. 召回率Recall
```
Recalli = TPi / GTi
```
属于这类的像素里，有多少被找回
#### 3. IoU
```
IoU = TPi / (GTi + Predi - TPi)
```
分母是“预测区域”和“真实区域”合在一起合在一起的面积，分子式两者重叠在一起的面积。完全重合时1，完全错开始0。
IoU同时惩罚两种错误：多标出去的(降低准确率)和漏掉的（降低召回率）。
IoU是评价类“分得像不像”的主指标
#### 4. Dice
``` 
Dicei = 2·TPi / (GTi + Predi) 

Dicei = 2·IoU / (1 + IoU) 
```
和IoU差不多
#### 5. PA 像素准确率
```
PA = ∑iTPi / N
```
N是全部有效像素。
PA是预测正确像素占全部像素的正确率，表明整张图看的对不对。
#### 6. mPA 平均召回率
```
mPA = 1/C (∑iRecalli)
``` 
C是类别，所有类别的平均准确率。
#### 7. mIoU 平均IoU
```
mIoU = 1/C (∑iIoUi)
```
所有类的平均IoU。
看整体分得对不对的主指标。
#### 8. FWIoU 
FWIoU：按频率加权的IoU
```
FWIoU = (∑i(IoUi * IoUi))/N 
```
按面积看，整图重叠好不好
