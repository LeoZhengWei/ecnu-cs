# 语义分割实验报告

## 1. 任务

在课程给出的 U-Net 代码上实现多类语义分割。数据集自行下载，不使用课堂数据。主模型是残差 U-Net，另用一个去掉跳跃连接的编码器-解码器做对照。测试指标在训练结束后计算，选模型只用验证集。

## 2. 数据集

使用 CamVid 驾驶场景数据集（Brostow, Fauqueur, Cipolla, *Pattern Recognition Letters*, 2009）。图像来自车载摄像头，原始标注为 32 个语义类。本次从公开镜像 `https://s3.amazonaws.com/fast-ai-imagelocal/camvid.tgz` 下载，共 701 张 960×720 彩色图及对应标注，由 `download_camvid.py` 完成校验和解压。

32 类按 SegNet 的常用规则合并为 11 类。`Void` 的编号记为 255，不进入损失，也不进入指标。

| 合并后类别 | 包含的原始类 |
| --- | --- |
| 天空 Sky | Sky |
| 建筑 Building | Building, Wall, Archway, Bridge, Tunnel |
| 杆柱 Pole | Column_Pole, TrafficCone |
| 道路 Road | Road, LaneMkgsDriv, LaneMkgsNonDriv |
| 人行道 Pavement | Sidewalk, ParkingBlock, RoadShoulder |
| 树木 Tree | Tree, VegetationMisc |
| 标志 SignSymbol | SignSymbol, Misc_Text, TrafficLight |
| 围栏 Fence | Fence |
| 车辆 Car | Car, SUVPickupTruck, Truck_Bus, Train, OtherMoving |
| 行人 Pedestrian | Pedestrian, Child, CartLuggagePram, Animal |
| 骑行者 Bicyclist | Bicyclist, MotorcycleScooter |
| 忽略 | Void |

划分：

- `valid.txt` 中的 101 张全部来自 `0016E5` 这一段行驶序列，作为测试集。

## 3. 代码设计与实现

沿用课程目录，各文件的职责如下。

| 文件 | 作用 |
| --- | --- |
| `download_camvid.py` | 下载并校验 CamVid |
| `dataset.py` | 读图、32 类合并、划分、同步增强、类别权重 |
| `model/block.py` | 残差卷积块，与课程样例相同 |
| `model/net.py` | 多类残差 U-Net，以及去掉跳跃连接的对照网络 |
| `model/training.py` | 训练、验证、按 mIoU 保存权重、测试 |
| `evaluate/metrics.py` | 由混淆矩阵计算各项指标 |
| `configs/config_loader.py` | 学习率、轮数、分辨率等参数 |
| `main.py` | 训练入口；结束后用最优权重评估测试集 |

课程样例是单通道输入、单通道输出，末尾接 sigmoid，损失是二元交叉熵，适合前景和背景两类。语义分割要给每个像素一个类别，因此改为 3 通道输入、11 通道 logits，损失改为带类别权重的交叉熵，预测时对通道做 `argmax`。

残差块的计算是：\(3\times3\) 卷积、ReLU、再一次 \(3\times3\) 卷积，然后与捷径相加并 ReLU。通道数变化时捷径为 \(1\times1\) 卷积，否则为恒等映射。

## 4. 网络结构

两个模型的基础通道数都是 64。输入 \(3\times240\times320\) 时，四次池化后的空间尺寸依次为 \(240\times320\)、\(120\times160\)、\(60\times80\)、\(30\times40\)，瓶颈为 \(15\times20\)。

### 4.1 残差 U-Net

编码器通道为 64、128、256、512，瓶颈为 1024。下采样使用 \(2\times2\) 最大池化。解码器用步长为 2 的转置卷积把分辨率放大一倍，再与编码器同尺度特征在通道维拼接，然后进入残差块。因为拼接，解码器每一级的输入通道是该级通道数的两倍。最后用 \(1\times1\) 卷积得到 11 个类别的 logits，不再接 sigmoid。

可训练参数为 32,428,171。

跳跃连接对应 `model/net.py` 中的

```python
dec4 = self.dec4(torch.cat((self.upconv4(bottleneck), enc4), dim=1))
```

放大后的特征提供语义，`enc4` 保留池化前的边缘和位置。

### 4.2 对照网络

对照网络使用同一套残差编码器和四级转置卷积上采样。解码器不拼接编码器特征，只处理上一层上采样的结果，因此每一级解码器的输入通道不加倍。它逐级放大，而不是把瓶颈一次放大 16 倍。两边的差别集中在有没有跳跃连接。

可训练参数为 28,597,451。参数更少，是因为解码器卷积的输入通道更少。

## 5. 训练过程与参数

两个模型使用同一套超参数，分别执行 `python main.py --model unet` 和 `python main.py --model fcn`。

| 项目 | 取值 |
| --- | --- |
| 输入 | \(3\times240\times320\)，像素值在 \([0,1]\) |
| 输出 | 11 类 logits |
| 优化器 | AdamW |
| 学习率 | \(3\times10^{-4}\) |
| 权重衰减 | \(1\times10^{-4}\) |
| 学习率调度 | 余弦退火，周期等于总轮数 |
| 损失 | 加权交叉熵，忽略编号 255 |
| 梯度裁剪 | 全局范数上限 1.0 |
| 数值精度 | CUDA 上使用 bfloat16 |
| batch size | 8 |
| 轮数 | 40 |
| 随机种子 | 42 |
| 设备 | NVIDIA RTX 5090 |
| 选模 | 每轮计算验证集 mIoU，保留最高的一次 |

一个有效像素上的加权交叉熵是

\[
\mathcal{L}=-\sum_{c=0}^{10} w_c\, y_c \log p_c
\]

\(y_c\) 是该像素的 one-hot 标签，\(p_c\) 是 softmax 后的概率，\(w_c\) 是第 2 节的类别权重。

每轮约 2.4 秒。U-Net 的最佳验证结果出现在第 33 轮：验证损失 0.8316，验证 mIoU 0.4500，验证 PA 0.7857。对照网络也在第 33 轮达到最佳验证 mIoU 0.4425，验证 PA 0.7810。权重分别保存在 `runs/unet/best.pth` 和 `runs/fcn/best.pth`。

## 6. 指标的计算方法

在测试集上把全部有效像素累加成混淆矩阵 \(M\)。行是真实类别，列是预测类别，\(M_{ij}\) 表示真实为 \(i\)、预测为 \(j\) 的像素数。Void 不进入矩阵。记

\[
TP_i=M_{ii},\quad
GT_i=\sum_j M_{ij},\quad
Pred_i=\sum_j M_{ji},\quad
N=\sum_{ij}M_{ij}
\]

| 指标 | 计算 | 作用 |
| --- | --- | --- |
| Precision\(_i\) | \(TP_i/Pred_i\) | 预测为该类的像素里有多少是对的 |
| Recall\(_i\) | \(TP_i/GT_i\) | 该类真实像素里有多少被找回来 |
| IoU\(_i\) | \(TP_i/(GT_i+Pred_i-TP_i)\) | 预测区域与真实区域的交并比 |
| Dice\(_i\) | \(2TP_i/(GT_i+Pred_i)\) | 与 IoU 单调对应，\(\mathrm{Dice}=2\mathrm{IoU}/(1+\mathrm{IoU})\) |
| PA | \(\sum_i TP_i/N\) | 全部有效像素的准确率 |
| mPA | \(\mathrm{mean}_i(\mathrm{Recall}_i)\) | 各类召回率的平均，每个类一票 |
| mIoU | \(\mathrm{mean}_i(\mathrm{IoU}_i)\) | 各类交并比的平均，模型对比以它为准 |
| mDice | \(\mathrm{mean}_i(\mathrm{Dice}_i)\) | 各类 Dice 的平均 |
| FWIoU | \(\sum_i (GT_i/N)\cdot\mathrm{IoU}_i\) | 按真实像素占比加权的 IoU |

某一类若没有像素，该项不参与平均。本次测试集 11 类都有像素。实现位于 `evaluate/metrics.py`。

PA 和 FWIoU 受道路、天空这类大区域支配。mIoU 对杆柱、行人这类小目标同样敏感，因此用 mIoU 比较模型，再用 Precision 和 Recall 解释某个类的 IoU 是被漏检拉低，还是被误检拉低。

## 8. 结果分析

大面积类别已经学到。U-Net 的天空 IoU 为 0.9381，道路为 0.8672，树木为 0.7244，人行道为 0.6744。道路精确率 0.9986，说明预测成道路的像素几乎都是道路。

像素准确率 0.7563 高于“只预测道路”的水平：道路约占训练像素的 29.84%。mIoU 为 0.4710，低于 PA，因为 11 个类等权平均，杆柱、标志和行人把均值拉低。FWIoU 为 0.6686，介于二者之间，说明按面积看，大类的重叠是好的。

细类的失误方式不同。行人召回率 0.7698、精确率 0.1674：大部分行人像素被找到了，但模型把许多不是人的位置也标成了人，IoU 只有 0.1594。建筑精确率 0.8453、召回率 0.4825：预测成建筑的区域比较干净，但大约一半真实建筑被标成了别的类。围栏召回率 0.9111、精确率 0.3121，同样是圈得偏大。杆柱 IoU 只有 0.0234。四次下采样后特征图只剩 \(15\times20\)，杆柱往往不到一个像素宽，上采样很难还原。

U-Net 的测试 mIoU 比对照网络高 0.0102（0.4710 对 0.4608），PA 高 0.0187。差距主要来自需要边界的类别：天空、建筑、杆柱、标志、车辆和行人。对照网络在树木、人行道和骑行者上更高，树木 IoU 达到 0.8426。跳跃连接在这个分辨率上带来了稳定但不大的整体提升，细结构仍然受下采样限制。

测试集是同一段视频的连续帧，帧与帧相关。验证集来自其他序列。U-Net 验证 mIoU 0.4500，测试 mIoU 0.4710，两者接近，说明结果不是只记住了这一段路。

## 9. 小结

实验在 CamVid 上完成了 11 类语义分割。网络是课程中的残差 U-Net，损失由二元交叉熵改为按类别频率加权的交叉熵，并用去掉跳跃连接的编码器-解码器做对照。测试集上 U-Net 的像素准确率为 0.7563，mIoU 为 0.4710；对照网络为 0.7376 和 0.4608。道路、天空等大类可靠，杆柱和行人的 IoU 仍然较低。
