# 语义分割实验报告

## 1. 任务与做法

本实验在课程给出的 U-Net 代码框架上实现多类语义分割。数据集不使用课堂材料，改为公开的 CamVid 驾驶场景数据集。网络保留课程中的残差 U-Net，并增加一个去掉跳跃连接的编码器-解码器作为对照。测试指标在训练结束后、用验证集选出的权重上计算，测试集不参与选模型。

## 2. 数据集

CamVid（Cambridge-driving Labeled Video Database）由车载摄像头采集，原始标注把每个像素标成 32 个语义类之一。

- 论文：Brostow, Fauqueur, Cipolla. *Semantic object classes in video: A high-definition ground truth database.* Pattern Recognition Letters, 2009.
- 下载镜像：`https://s3.amazonaws.com/fast-ai-imagelocal/camvid.tgz`（701 张 960×720 彩色图及对应标注）。脚本见 `download_camvid.py`。

32 类按 SegNet 的常用规则合并成 11 类，`Void` 不参与损失和指标（`ignore_index=255`）。

| 合并后类别 | 包含的原始类 |
| --- | --- |
| 天空 Sky | Sky |
| 建筑 Building | Building, Wall, Archway, Bridge, Tunnel |
| 杆柱 Pole | Column_Pole, TrafficCone |
| 道路 Road | Road, LaneMkgsDriv, LaneMkgsNonDriv |
| 人行道 Pavement | Sidewalk, ParkingBlock, RoadShoulder |
| 树木 Tree | Tree, VegetationMisc |
| 标志 SignSymbol | SignSymbol, Misc_Text, TrafficLight |
| 围栏 Fence | Fence |
| 车辆 Car | Car, SUVPickupTruck, Truck_Bus, Train, OtherMoving |
| 行人 Pedestrian | Pedestrian, Child, CartLuggagePram, Animal |
| 骑行者 Bicyclist | Bicyclist, MotorcycleScooter |
| 忽略 | Void |

划分方式：

- 发布包里的 `valid.txt` 共 101 张，全部来自 `0016E5` 这一段行驶序列，作为**测试集**。
- 其余 600 张按随机种子 42 打乱，15%（90 张）做**验证集**，用于保存验证 mIoU 最高的权重；剩下 510 张做**训练集**。

图像从 960×720 双线性缩放到 320×240（高 240、宽 320，与原图 4:3 一致，且能被 16 整除，方便 4 次下采样）。标注用最近邻缩放，避免类别编号被插值混在一起。

## 3. 代码结构

沿用课程目录，主要改动如下。

| 文件 | 作用 |
| --- | --- |
| `download_camvid.py` | 下载并解压 CamVid |
| `dataset.py` | 读图和标注、32 类合并、划分、增强、类别权重 |
| `model/block.py` | 残差卷积块，与课程样例相同 |
| `model/net.py` | 多类残差 U-Net，以及去掉跳跃连接的对照网络 |
| `model/training.py` | 训练、验证、按 mIoU 存最优权重、测试 |
| `metrics.py` | 由混淆矩阵计算 PA、mPA、IoU、Dice 等 |
| `main.py` | 训练入口，训练结束后在测试集上评估最优权重 |
| `evaluate.py` | 对比两个模型、画曲线和预测图 |
| `infer/infer.py` | 对单张或一个目录做彩色预测 |
| `configs/config_loader.py` | 学习率、轮数、分辨率等参数 |

课程样例是单通道输入、单通道输出，最后接 sigmoid，损失是二元交叉熵，适合前景/背景分割。语义分割要为每个像素输出一个类别，因此这里改成 3 通道输入、11 通道 logits，损失改为带类别权重的交叉熵，预测时对通道做 `argmax`。

运行方式：

```bash
python download_camvid.py
python main.py --model unet
python main.py --model fcn
python evaluate.py
```

## 4. 网络结构

两个模型共用同一种残差卷积块。记输入为 \(x\)：

1. \(3\times3\) 卷积，通道变为 \(C_{out}\)，ReLU
2. 再一次 \(3\times3\) 卷积
3. 与捷径相加后 ReLU。通道数变化时，捷径是 \(1\times1\) 卷积，否则是恒等映射

### 4.1 残差 U-Net

这是课程 `UNet` 的多类版本。基础通道数 64，四级编码器，通道数为 64、128、256、512，瓶颈为 1024。下采样是 \(2\times2\) 最大池化。解码器用步长为 2 的转置卷积把分辨率放大一倍，再与编码器同尺度特征在通道维拼接，然后进入残差块。最后用 \(1\times1\) 卷积得到 11 个类别的 logits，不再接 sigmoid。

输入 \(240\times320\) 时，各阶段空间尺寸为 \(240\times320\)、\(120\times160\)、\(60\times80\)、\(30\times40\)、瓶颈 \(15\times20\)，再逐级上采样回 \(240\times320\)。

可训练参数：**32,428,171**。

### 4.2 对照模型 FCN

对照网络使用同一套残差编码器和同样的四级转置卷积上采样，但解码器不拼接编码器特征，只处理上一层上采样的结果。这样两者的差别集中在有没有跳跃连接。它不是把瓶颈一次放大 16 倍的 FCN-32s，而是逐级上采样的编码器-解码器，所以本身并不弱。

可训练参数：**28,597,451**。参数少于 U-Net，是因为解码器输入没有拼上编码器特征，卷积的输入通道更少。

## 5. 训练设置

两个模型使用同一套超参数，只更换网络。

| 项目 | 取值 |
| --- | --- |
| 输入 | \(3\times240\times320\)，像素缩放到 \([0,1]\) |
| 输出 | 11 类 logits |
| 优化器 | AdamW |
| 学习率 | \(3\times10^{-4}\)（与课程样例相同） |
| 权重衰减 | \(1\times10^{-4}\) |
| 学习率调度 | 余弦退火，周期等于总轮数 |
| 损失 | 加权交叉熵，忽略 Void |
| 梯度裁剪 | 全局范数上限 1.0 |
| 精度 | CUDA 上使用 bfloat16 混合精度 |
| batch size | 8 |
| 轮数 | 40 |
| 随机种子 | 42 |
| 设备 | NVIDIA RTX 5090 |
| 选模 | 每轮在验证集上算 mIoU，保留最高的一次 |

加权交叉熵对一个有效像素写成

\[
\mathcal{L}=-\sum_{c=0}^{10} w_c\, y_c \log p_c
\]

其中 \(y_c\) 是该像素的 one-hot 标签，\(p_c\) 是 softmax 之后的概率，\(w_c\) 是上一节的类别权重。标注为 255 的像素不进入损失。

每轮约 2.4 秒，单个模型大约 2 分钟。U-Net 的最佳验证 mIoU 出现在第 33 轮，为 0.4538；对照模型也在第 33 轮达到最佳验证 mIoU 0.4434。训练曲线见下图：损失持续下降，验证 mIoU 在 30 轮之后趋平。

## 6. 指标怎么算

在测试集上把全部有效像素累加成混淆矩阵 \(M\)。行是真实类别，列是预测类别，\(M_{ij}\) 表示真实为 \(i\)、预测为 \(j\) 的像素数。Void 不进入矩阵。记

\[
TP_i=M_{ii},\quad
GT_i=\sum_j M_{ij},\quad
Pred_i=\sum_j M_{ji},\quad
N=\sum_{ij}M_{ij}
\]

则各类和总体指标为：

| 指标 | 计算 | 含义 |
| --- | --- | --- |
| IoU\(_i\) | \(TP_i/(GT_i+Pred_i-TP_i)\) | 该类交并比 |
| Precision\(_i\) | \(TP_i/Pred_i\) | 预测为该类的像素里有多少是对的 |
| Recall\(_i\) | \(TP_i/GT_i\) | 该类真实像素里有多少被找回来 |
| Dice\(_i\) | \(2TP_i/(GT_i+Pred_i)\) | 与 IoU 单调对应的重叠系数 |
| PA | \(\sum_i TP_i/N\) | 像素准确率 |
| mPA | \(\mathrm{mean}_i(\mathrm{Recall}_i)\) | 各类召回率的平均，不受像素多少影响 |
| mIoU | \(\mathrm{mean}_i(\mathrm{IoU}_i)\) | 语义分割最常用的总指标 |
| mDice | \(\mathrm{mean}_i(\mathrm{Dice}_i)\) | 各类 Dice 的平均 |
| FWIoU | \(\sum_i (GT_i/N)\cdot\mathrm{IoU}_i\) | 按真实像素频率加权的 IoU |

某一类如果在该划分里没有像素，对应项记为缺失，平均值用 `nanmean`，不把空类算成 0。本次测试集 11 类都有像素。实现和一组手算样例在 `metrics.py`，直接运行 `python metrics.py` 可以核对 PA 和 IoU。

像素准确率会被道路、天空这类大区域拉高；mIoU 对杆柱、行人类小目标更敏感，所以报告以 mIoU 为主，同时给出 PA、mPA、FWIoU 和 mDice。

## 8. 结果说明

大面积类别已经学到了。天空 IoU 0.94，道路 0.89，树木 0.78，人行道 0.69。定性图里路面、天空、建筑和树冠的区域与标注一致，车和骑行者能被大致圈出来。

像素准确率 0.75 明显高于“永远预测道路”的水平（道路只占训练像素的约 30%）。mIoU 只有 0.47，是因为杆柱、标志、行人这几类很细、像素很少。四次下采样之后，特征图只剩 \(15\times20\)，杆柱往往只占一两个像素，上采样很难还原。行人和标志的召回并不低（行人召回 0.74，标志 0.57），但精确率只有 0.10 左右：类别权重把这些类抬高以后，模型倾向于多预测它们，IoU 就被假阳性拉低。

两个模型的 mIoU 只差约 0.9 个百分点，对照模型略高。跳跃连接的好处主要体现在细结构上：U-Net 的杆柱、标志、道路、天空和车辆 IoU 更高。对照模型在树木、骑行者和行人上更高，把总 mIoU 拉了过去。对照模型并不是一次放大 16 倍的粗糙 FCN，它和 U-Net 一样逐级上采样，只是没有拼接浅层特征，因此在 240×320 这种分辨率上两者接近是合理的。

测试集是同一段视频的连续帧，帧与帧相关，数值会比打乱后的混合测试集好看一些。验证集来自其他序列，U-Net 验证 mIoU 0.4538，与测试 0.4659 接近，说明没有只在这一段路上过拟合。

## 9. 小结

实验用 CamVid 完成了 11 类语义分割。网络是课程中的残差 U-Net，损失由二元交叉熵改为按类别频率加权的交叉熵，并用一个去掉跳跃连接的编码器-解码器做对照。测试集上 U-Net 的像素准确率为 0.7474，mIoU 为 0.4659；对照模型为 0.7659 和 0.4752。道路、天空等大类可靠，杆柱和行人受分辨率和类别极不均衡的限制，IoU 仍然较低。
