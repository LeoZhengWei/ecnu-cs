## 四、为跑通本机所做的最小改动（重要）

原始仓库直接按 README 装完是跑不起来的。以下 9 处是本机实际遇到并修掉的，按发生顺序：

1. **`third_party/glm` 为空导致光栅化器编译失败**
   → `git submodule update --init --recursive`。`--recursive` 必须带，否则只展开第一层子模块。

2. **`weights/xfeat-lighterglue.pt` 从 github.com 直连下载被重置**
   → 改 `poses/lighterglue_matcher.py`：`weights_path` 为空时优先用仓库内的
   `submodules/xfeat/weights/xfeat-lighterglue.pt`，不再走网络（标记 `[LOCAL PATCH]`）。

3. **`torch.hub` 需联网拉 `verlab/accelerated_features` 与 `gmberton/MegaLoc`**
   → 预先把两个仓库代码包解压到 `~/.cache/torch/hub/`，`xfeat.pt` 等放进
   `~/.cache/torch/hub/checkpoints/`，命中缓存后不再联网。

4. **MegaLoc 半精度加载与聚合模块 float 参数冲突**（`expected scalar type Float but found Half`）
   → `scene/vpr_model.py` 中 `model.half()` 改 `model.float()`，并删除 `models/cache/` 下的旧 jit 缓存。

5. **VPR 前向硬写 `img.half()`，与 float 参数再次冲突**
   → 改为跟随骨干网 dtype：
   ```python
   _dt = next(self.model.parameters()).dtype
   img = F.interpolate(img.to(_dt), size=(self.run_h, self.run_w), ...)
   ```

6. **必须在 `i3dgs/` 目录下运行**
   代码用 `poses/ransac.cu`、`submodules/Depth-Anything-V2` 这类**相对 cwd 的路径**。
   在仓库根目录执行 `python i3dgs/train.py` 会报
   `FileNotFoundError: poses/ransac.cu`。

7. **Depth-Anything-3 的依赖链缺失**（因 `--no-deps` 安装）
   依次报 `omegaconf` → `moviepy` → `einops` → `matplotlib` → `pycolmap` → `evo`。
   用第二节最后一行一次性补齐即可。

8. **DA3 权重直连 HuggingFace 会挂死**（进程卡在 `SYN-SENT`，GPU 占着但利用率为 0）
   → 预先 `snapshot_download("depth-anything/DA3-BASE", local_dir=checkpoints/DA3-BASE)`，
   运行时显式 `--da3_model_dir` 指向本地目录，并设 `HF_HUB_OFFLINE=1`。
   DA3 的 `__init__` 会先尝试 `local_files_only=True`，命中本地后完全不联网。

9. **Depth-Anything-V2 子模块目录为空**
   GitHub 直连失败时 `git submodule update` 拿不到内容，
   → 用 `codeload.github.com/DepthAnything/Depth-Anything-V2/tar.gz/refs/heads/main` 下 tarball 解压到
   `submodules/Depth-Anything-V2`；同时把 `depth_anything_v2_vits.pth`（95 MB）预下到
   `i3dgs/models/`（代码里写死了这个相对路径）。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `glm/glm.hpp: No such file` | 嵌套子模块未初始化 | `git submodule update --init --recursive` |
| `Connection reset by peer` | github.com 直连不稳定 | 用 `codeload.github.com` 下 tarball，或走本地缓存 |
| `FileNotFoundError: poses/ransac.cu` | 工作目录不对 | `cd i3dgs` 后再运行 |
| 进程活着但 GPU 利用率 0%、`ss` 显示 `SYN-SENT` | 在直连 HuggingFace 下权重 | 预下载权重 + `HF_HUB_OFFLINE=1` |
| `Input type (Half) and bias type (float)` | VPR 输入 dtype 写死 | 见第四节第 4、5 条 |
| `No module named 'moviepy.editor'` | 装了 moviepy 2.x | `pip install moviepy==1.0.3` |
| `CUDA out of memory` | 卡被其他任务占用 | 用 `auto_train.sh` 自动等卡/降分辨率，或 `--downsampling 8` |
| 首帧很慢 | 首次 JIT 编译 + DA3 加载 | 正常，之后帧率稳定 |
